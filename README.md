# 🪐 ZeroBoard

> An ultra-lightweight, infinite-canvas workspace for tasks, routines, and quick notes. Built as a single HTML file with zero external dependencies and 100% local-first storage.

---

## ⚡ Highlights

- **Single-File Architecture**: No Node.js, no build steps, no external packages. The entire application runs directly from `index.html`.
- **Infinite Dotted Canvas**: Pan and organize floating cards freely across a spatial dotted grid.
- **Draggable & Resizable Sections**: Drag cards by their headers to rearrange them; resize freely from the bottom-right corner grip.
- **Dynamic 10-Color Cycle**: Click the color indicator circle on any card to cycle through 10 curated accent themes with ambient glow and full container tinting.
- **Flexible Modes**: Add checklist items with custom rounded indicators, or toggle into clean bulleted text notes.
- **Board Pages (Tabs)**: Create and switch between multiple dedicated workspaces (e.g., *Daily Routines*, *Weekly Goals*, *Demo Accounts*).
- **100% Local & Private**: All card positions, dimensions, active tabs, and tasks persist immediately in your browser's `localStorage`.
- **Native Dark / Light Modes**: Smooth theme switching with contrast optimized for distraction-free sessions.
